# Project Archive

Independent Mechanical Watch Projects.

A photographic journal of PROJECT No. 001, a one-of-one custom automatic field watch. The archive follows the initial concept, dial design, components, assembly and completed watch.

- [Live archive](https://ddwatches.github.io/project-archive/)
- [PROJECT No. 001](https://ddwatches.github.io/project-archive/project-001/)

## Site

Static HTML and shared CSS. No build step, framework or package manager is required. Fonts and images are served locally; the pages contain no JavaScript.

- `index.html` — archive homepage.
- `project-001/index.html` — project journal.
- `style.css` — typography and responsive layouts.
- `assets/` — selected photographs, design studies, technical illustrations and fonts.

## Preview

Run `python3 -m http.server 8000` in the repository, then open http://localhost:8000/.

## Publishing

GitHub Pages publishes the `main` branch from `/(root)`. Relative links support the `/project-archive/` project-site path. The earlier `project-archive-v1/` upload is retained for existing links.

Image-editing masters, production notes and local source metadata are retained locally and excluded from the public release. Published photographs have responsive sizes, descriptive alternative text and full-size links where provided.
